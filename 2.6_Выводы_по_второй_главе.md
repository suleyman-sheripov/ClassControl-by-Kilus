# 2.6 Выводы по второй главе

Во второй главе выполнено проектирование системы «ClassControl». Выбрана смешанная сетевая структура: централизованная модель используется для передачи команд, а прямые соединения — для трансляции видео. Это снижает общую нагрузку на сервер и уменьшает задержки при показе экрана.

Система разделена на три основных модуля: настольное приложение преподавателя, фоновый агент локального ученика и клиент в обозревателе для удаленных участников. Для каждого из модулей определены базовые задачи.

Разработаны алгоритмы взаимодействия компонентов. Механизм автоматического обнаружения сервера позволяет запускать систему в классах без ручной настройки сетевых адресов, а алгоритм покадрового сжатия снимков экрана снижает объем передаваемых по локальной сети данных.

Также определена структура хранения данных. Оперативная память используется для хранения снимков доски и списка подключений, а жесткий диск — для сохранения видеозаписей и загружаемых файлов. Отказ от полноценных баз данных упрощает развертывание и поддержку приложения.

Спроектированная архитектура и алгоритмы будут использованы для программной реализации интерфейсов и тестирования системы, что рассматривается в третьей главе.
