## 3.2 Программная реализация серверной части

Серверная часть системы «ClassControl» полностью реализована на базе платформы Node.js с использованием фреймворка Express. Основной задачей выделенного сервера является централизованная маршрутизация управляющих команд, обмен сигнальными сообщениями WebRTC и обеспечение автоматического обнаружения клиентов в классе.

Для решения проблемы ручной настройки и ввода адресов в локальной сети был программно реализован механизм широковещательного автоматического поиска. Сервер открывает доступ и прослушивает сеть на наличие запросов от запускаемых агентов учеников. При получении запроса сервер отправляет ответ, по которому программа ученика автоматически устанавливает постоянное сетевое соединение.

В листинге 3.1 показан фрагмент кода запуска сервера и обработки широковещательных запросов.

```javascript
const dgram = require('dgram');
const udpServer = dgram.createSocket('udp4');

udpServer.on('message', (msg, rinfo) => {
    const messageStr = msg.toString();
    if (messageStr === 'DISCOVER_CLASSCONTROL_SERVER') {
        const response = Buffer.from('CLASSCONTROL_SERVER_HERE');
        udpServer.send(response, rinfo.port, rinfo.address, (err) => {
            if (err) console.error('[UDP] Ошибка отправки ответа:', err);
        });
    }
});

udpServer.bind(41234, () => {
    console.log('[UDP] Discovery server listening on port 41234');
});
```
*Листинг 3.1 — Реализация механизма UDP Discovery на стороне сервера*

Параллельно с механизмом поиска, для двустороннего обмена данными развернут сервер, обеспечивающий обработку событий реального времени. В его реализацию заложена логика подтверждения прав по ролям, распределение подключений и обработка потока изображений мониторинга. При отключении пользователя сервер корректно очищает временные данные в оперативной памяти и оповещает остальных участников о статусе сети.
