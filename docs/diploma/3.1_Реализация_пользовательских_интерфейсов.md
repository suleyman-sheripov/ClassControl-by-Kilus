# 3 ПРОГРАММНАЯ РЕАЛИЗАЦИЯ И ТЕСТИРОВАНИЕ

В данной главе рассматриваются практические аспекты программной реализации системы «ClassControl». Разработана серверная часть, реализована логика сетевого обмена в реальном времени, а также созданы пользовательские интерфейсы для всех ролей: преподавателя, локального агента и удаленного клиента.

## 3.1 Программная реализация пользовательских интерфейсов

Визуальная часть разрабатываемой системы построена с использованием встроенных интернет-технологий (HTML5, CSS3, чистый JavaScript) без применения тяжеловесных программных каркасов. Это решение позволило добиться мгновенного отклика интерфейса и существенно снизить потребление оперативной памяти клиентскими приложениями.

**Интерфейс приложения обозревателя**
Модуль клиента полностью реализован и функционирует через любой современный обозреватель. При переходе по сетевому адресу сервера пользователь попадает на минималистичный экран подтверждения входа, где требуется ввести свое имя. Внешний вид окна входа представлен на рисунке 3.1.

После успешного входа открывается основное рабочее пространство. Оно логически разделено на две зоны: слева располагается широкая область приема видеотрансляции или просмотра доски, справа — панель области сообщений. В нижней части экрана реализована кнопка «Показать мой экран». При ее нажатии интерфейс динамически меняется: начинается перехват экрана пользователя и запускается визуальный счетчик обратного отсчета на 5 минут, после чего трансляция прерывается. **Интерфейс приложения преподавателя**
Графический интерфейс преподавателя спроектирован для настольного использования и имеет плотную, информативную компоновку в виде макета в три столбца, что показано на рисунке 3.3. Данный подход позволяет преподавателю управлять уроком без переключений между окнами.

* **Левый столбец:** отведен под списки участников, разделенные на локальных и удаленных, и область сообщений класса с поддержкой обмена файлами.
* **Центральная колонка:** динамическая область, переключаемая вкладками. В режиме «Мониторинг» отображается сетка карточек с трансляцией рабочих столов учеников с частотой один кадр в секунду. В режиме «Доска» сетка сменяется полноэкранным элементом с панелью инструментов для рисования.
* **Правый столбец:** представляет собой студию управления трансляцией. Она содержит область предварительного просмотра, переключатели разрешения и частоты кадров, а также элементы управления записью урока.
