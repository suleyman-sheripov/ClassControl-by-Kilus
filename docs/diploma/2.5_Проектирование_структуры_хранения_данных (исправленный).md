# 2.5 Проектирование структуры хранения данных

В отличие от обычных информационных систем, специфика системы «ClassControl» не требует использования сложных баз данных. Приложение работает в рамках одного занятия: почти вся информация актуальна только во время проведения текущего урока. В связи с этим структура хранения разделена на два простых уровня: оперативную память компьютера и постоянное хранение на жестком диске.

**1. Временное хранение в оперативной памяти**
Центральный сервер выступает главным хранилищем актуальной информации о текущем уроке. В его памяти находятся:
* **Список программ-агентов:** содержит имена компьютеров в классе, их сетевые адреса и статусы присутствия учеников.
* **Список удаленных участников:** похожий список для тех, кто занимается из дома через обозреватель.
* **Состояние трансляции:** отметка о том, идет ли в данный момент показ экрана учителя. При подключении нового ученика сервер проверяет эту отметку и сразу дает команду открыть окно с видео.
* **Снимок интерактивной доски:** набор координат нарисованных линий или готовое изображение. Это нужно для того, чтобы опоздавший ученик увидел актуальное состояние доски, а не пустой экран.

**2. Постоянное хранение файлов на диске**
Информация, которая должна сохраниться после завершения урока, записывается на жесткий диск компьютера:
* **Видеозаписи уроков:** при включении записи приложение преподавателя сохраняет захваченное видео и звук в специальную папку.
* **Файловый обмен:** если участник отправляет документ в общую беседу, файл физически сохраняется на диске сервера. В самом сообщении передается только ссылка на его скачивание, что позволяет не перегружать сеть.
* **Настройки агентов:** локальные правила для компьютеров учеников, включая запрет на закрытие программы и параметры автозапуска, сохраняются в системном реестре операционной системы.

Спроектированная комбинированная структура хранения обеспечивает высокую скорость обмена данными во время урока и надежное сохранение учебных материалов без лишней нагрузки и необходимости настраивать базы данных.
