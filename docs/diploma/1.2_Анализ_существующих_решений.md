# 1.2 Анализ существующих решений

Для обоснования целесообразности разработки собственной системы «ClassControl» был проведен анализ представленных на рынке программных продуктов. Традиционно решения в этой области делятся на две изолированные категории: локальные системы управления классом и платформы для видеосвязи. В рамках исследования были рассмотрены наиболее популярные аналоги: Veyon, LiteManager и Google Meet.

**Veyon** — это кроссплатформенное программное обеспечение с открытым исходным кодом для мониторинга компьютеров и управления классом. Внешний вид главного экрана системы со стороны преподавателя представлен на рисунке 1.2.

**Рисунок 1.2 — Интерфейс панели мониторинга в системе Veyon**

* *Преимущества:* Система является бесплатной, позволяет просматривать экраны учеников в виде сетки миниатюр, транслировать экран преподавателя и дистанционно управлять рабочими станциями. 
* *Ограничения:* Главным недостатком Veyon является его строгая привязка к локальной сети. Система не имеет встроенных механизмов для передачи трафика через интернет и не поддерживает подключение домашних учеников без сложной настройки туннелей. Кроме того, архитектура трансляции в Veyon не использует современные веб-протоколы, что делает невозможным подключение к уроку через обычный обозреватель.

**LiteManager** — популярный программный продукт для удаленного администрирования и управления компьютерными классами. Интерфейс панели преподавателя показан на рисунке 1.3.

**Рисунок 1.3 — Интерфейс преподавателя в системе LiteManager**

* *Преимущества:* Обладает интеграцией на уровне операционной системы, позволяет управлять рабочими столами, блокировать устройства ввода и имеет бесплатную версию с базовыми возможностями.
* *Ограничения:* Интерфейс системы перегружен избыточными функциями администрирования, которые не требуются для проведения детских ИТ-курсов. Кроме того, LiteManager слабо приспособлен для гибридного обучения, требуя установки отдельной программы для каждого дистанционного участника, а расширенные функции требуют покупки коммерческой лицензии.
