# ВВЕДЕНИЕ

В сфере дополнительного ИТ-образования все большую популярность приобретает смешанный формат занятий, при котором часть учеников находится непосредственно в компьютерном классе, а часть подключается удаленно через интернет. Управление таким распределенным классом требует постоянного контроля цифровой дисциплины и возможности быстрого оказания помощи каждому ребенку. Однако сегодня проведение такого урока зачастую ведется с использованием разрозненных инструментов: для связи с домашними участниками запускаются сторонние программы видеосвязи, а для проверки локальных заданий учителю приходится физически подходить к монитору каждого ученика. Основная сложность при этом — отсутствие единого пространства, где преподаватель мог бы одновременно видеть рабочие столы всего класса, дистанционно перехватывать управление мышью для исправления ошибок в коде и транслировать учебный материал без задержек. Это отнимает много времени, снижает темп занятия и повышает риск потери внимания у детей. Таким образом, разработка системы, которая позволит осуществлять мониторинг прямо из единого интерфейса и автоматизировать управление компьютерами учеников, является актуальной задачей для образовательной организации.

Цель работы — разработать программную систему для автоматизации контроля и сопровождения гибридного учебного процесса.

Для достижения этой цели были поставлены следующие задачи:
* Изучение предметной области и специфики проведения смешанных ИТ-курсов.
* Анализ существующих программных решений и выявление проблем в текущих подходах к управлению классом.
* Формирование функциональных требований к разрабатываемой системе.
* Проектирование архитектуры приложения, базовых алгоритмов обмена данными и структуры их хранения.
* Проектирование графических интерфейсов пользователя.
* Программная реализация настольных и серверных компонентов системы с использованием современных интернет-технологий.
* Проведение тестирования разработанных модулей на соответствие заявленным требованиям.
