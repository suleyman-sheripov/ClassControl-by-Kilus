# 1.4 Обоснование выбора средств разработки

Для реализации кроссплатформенной системы «ClassControl» выбран единый набор технологий на базе **JavaScript**. Использование одного языка для серверной, клиентской и настольной частей минимизирует время разработки и упрощает поддержку кода.

Серверная часть построена на **Node.js**. Ее асинхронная архитектура оптимальна для поддержания множества одновременных сетевых подключений и быстрого обмена данными. Настольные приложения реализованы на **Electron.js**. Это обеспечивает не только кроссплатформенность, но и критически важный доступ к встроенным функциям операционной системы: скрытой фоновой работе агента, автоматическому запуску через реестр и перехвату управления мышью и клавиатурой.

Организация видеотрансляций базируется на стандарте **WebRTC**, гарантирующем прямую передачу медиаданных между узлами с минимальной задержкой без установки сторонних расширений. В качестве транспорта для обмена управляющими командами применяется **Socket.IO**, обладающий встроенными механизмами повторного подключения при обрывах связи.

Пользовательские интерфейсы разработаны с использованием стандартного набора **HTML5, CSS3 и чистого JavaScript**. Отказ от тяжеловесных программных каркасов, таких как React или Angular, продиктован жесткими требованиями к производительности: фоновые процессы системы мониторинга не должны замедлять работу программ, которые используют ученики на занятиях.
