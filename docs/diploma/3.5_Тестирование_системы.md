## 3.5 Тестирование системы

Для проверки работоспособности разработанной системы и выявления возможных ошибок было проведено тестирование основных модулей в условиях локальной сети. Процесс тестирования включал проверку серверного узла, клиента для обозревателя для удаленных участников и графического интерфейса преподавателя.

**Тестирование серверной части**
Запуск центрального сервера маршрутизации производился в среде Node.js. В процессе проверки было подтверждено, что сервер успешно запускается для обработки широковещательных запросов на порту 41234 и сетевых соединений на порту 3000. Встроенная система ведения журнала корректно фиксировала запуск, попытки подключения и регистрацию новых пользователей.

**Тестирование клиента для обозревателя**
Доступ к сетевому интерфейсу проверялся через современный обозреватель по локальному адресу сервера. При первом подключении корректно отображался экран авторизации, запрашивающий имя пользователя для входа, показанный на рисунке 3.4.

**Тестирование интерфейса преподавателя**
Графический интерфейс преподавателя тестировался на корректность отображения макета в три столбца и отклик интерактивных элементов. Сетка мониторинга и списки удаленных участников корректно обновлялись при появлении новых подключений. Функция интерактивной доски на базе встроенных средств отрисовки продемонстрировала отображение графических примитивов без задержек и успешную синхронизацию состояния с клиентом.

Проведенное тестирование подтвердило стабильность сетевого обмена и готовность пользовательских интерфейсов к эксплуатации.
