## Проверено в текущем Linux-окружении

- 44 автоматических теста: исходные серверные сценарии и новые регрессии — подписи/nonce, микрофоны, руки, конфиденциальность ответов, взаимопроверка, доступ к файлам, фигуры/отмена, 30 клиентов доски, некорректные данные и совместное владение панелью задач.
- Браузер: справка, создание теста, вход ученика, ответ с мгновенной проверкой, вопрос и очередь рук; без ошибок JavaScript.
- Настоящие Electron-приложения: подтверждённый агент, мониторинг и три последовательных подключения к видеопотоку ученика. Пройден цикл блокировки/разблокировки из карточки и доставка подписанного материала с проверкой SHA-256, квитанцией получения и видимыми кнопками открытия файла/папки.
- Эфир 10 и 30 FPS: агент получил оба потока; разрешение и режим `detail` неизменны, лимит битрейта вырос втрое.
- Проверены официальные контрольные суммы поставляемых cloudflared Windows x64 и macOS x64.

Результаты дополнительных проверок и ссылки на сборки добавляются после завершения CI. До этого наличие каталога `win-unpacked` не считается готовым установщиком.

## Границы проверки

- Низкоуровневый хук компилируется/запускается/снимается на Windows в CI (`scripts/test-windows-guard.js`). Физические сочетания клавиш, панель задач и разные масштабы экрана требуют проверки на настоящем Windows-ПК.
- Linux не доказывает работу разрешений записи экрана/микрофона и универсального доступа macOS. Для `.dmg` используется нативный macOS runner.
- Проверка 30 подключений — функциональная, а не замер загрузки CPU на слабых школьных ПК. Цель «не более 10%» на конкретном оборудовании пока не измерена.
- Анонимность взаимопроверки скрывает автора в интерфейсе и имени скачанного файла; содержимое и метаданные исходного документа могут содержать имя, поэтому это поясняется перед раздачей.
- Подпись защищает от сетевой подмены команд и материалов, но не шифрует LAN-трафик и не заменяет ограничения ОС для локального администратора.
- Категории «Узнать мнение» и «Организовать работу», звуковые сигналы рук, а также идеи с пометкой «Потом» не добавлялись согласно очередности исходного документа.

## Повторение проверок и сборка

```sh
npm ci
npm run setup
npm test
# Linux с X11-дисплеем:
xvfb-run -a npm run test:desktop
# На соответствующей ОС:
npm --prefix teacher run build:win
npm --prefix agent run build:win
npm --prefix teacher run build:mac
npm --prefix agent run build:mac
```

В GitHub Actions workflow «Сборка установщиков» собирает оба приложения. Файлы находятся в Artifacts соответствующего запуска; подпись платным сертификатом и публикация релиза автоматически не выполняются для рабочей ветки.
