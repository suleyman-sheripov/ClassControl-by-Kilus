# ClassControl — Полная инструкция по проверке

> [!IMPORTANT]
> Для полной проверки нужны **минимум 2 компьютера** (или 2 экземпляра на одном ПК).
> Для быстрой проверки на одном ПК используй раздел «Проверка на одном ПК».

---

## Подготовка

### 1. Убедись, что зависимости установлены

```bash
cd d:\Backup\Desktop\DEMO-DIPLOM\server
cmd /c npm install

cd d:\Backup\Desktop\DEMO-DIPLOM\teacher
cmd /c npm install

cd d:\Backup\Desktop\DEMO-DIPLOM\agent
cmd /c npm install
```

### 2. Убедись, что порт 3000 свободен

```bash
netstat -ano | findstr :3000
# Если занят — убить процесс:
taskkill /PID <номер_PID> /F
```

## Этап 1: Сервер

### Запуск
```bash
cd d:\Backup\Desktop\DEMO-DIPLOM\server
cmd /c node server.js
```

### Ожидаемый результат
```
[UDP] Discovery server listening on port 41234
[SERVER] Listening on port 3000
[SERVER] Web interface: http://localhost:3000
```

### Чеклист
- [ ] Сервер запустился без ошибок
- [ ] В консоли видно оба сообщения (HTTP + UDP)
- [ ] `http://localhost:3000` открывается в браузере

> [!NOTE]
> Сервер можно запустить отдельно или он запустится автоматически внутри Electron учителя. Для тестирования лучше **запускать отдельно** — так видны логи.

## Этап 2: Удаленный участник (Обозреватель)

### Запуск
Открой **http://localhost:3000** в браузере (при запущенном сервере).

### Список проверок — Экран входа
- [ ] Отображается карточка «ClassControl» по центру
- [ ] Есть поле ввода «Ваше имя» и кнопка «Присоединиться»
- [ ] Тёмная тема, шрифт Inter

### Список проверок — Вход
1. Ввести имя, например "Студент-1"
2. Нажать «Присоединиться»

- [ ] Экран входа исчезает
- [ ] Появляется основной интерфейс: видео-зона слева + область сообщений справа
- [ ] В видео-зоне надпись «Ожидание демонстрации учителя...»
- [ ] Внизу кнопка «📺 Показать мой экран (макс. 5 мин)»
- [ ] В журнале сервера: `Удаленный пользователь вошел: Студент-1`

### Список проверок — Область сообщений
1. Написать текст в поле ввода
2. Нажать «→» или Enter

- [ ] Сообщение появляется в окне с именем отправителя
- [ ] При повторной отправке — все сообщения отображаются подряд

### Список проверок — Показ экрана
1. Нажать «📺 Показать мой экран»
2. Выбрать окно/экран в системном диалоге

- [ ] Появляется таймер 05:00 (красный)
- [ ] Таймер отсчитывает вниз (04:59, 04:58…)
- [ ] Появляется кнопка «Остановить»
- [ ] Кнопка «Показать мой экран» скрывается
- [ ] При нажатии «Остановить» — таймер исчезает, показ прекращается
- [ ] Через 5 минут — показ автоматически停止

### Список проверок — Выход
- [ ] Кнопка «Выйти» перезагружает страницу и показывает экран входа

## Этап 3: Учитель (Electron)

> [!WARNING]
> Если сервер уже запущен отдельно — закомментируй строку `require('../server/server.js')` в `teacher/main.js`, иначе будет конфликт портов

### Запуск
```bash
cd d:\Backup\Desktop\DEMO-DIPLOM\teacher
cmd /c .\node_modules\.bin\electron.cmd .
```

### Список проверок — Главное окно
- [ ] Открывается окно «ClassControl — Учитель»
- [ ] Тёмная тема, 3 колонки:
  - Левая: участники + чат
  - Центр: сетка мониторинга
  - Правая: студия трансляции

### Список проверок — Навигация (Вкладки)
1. Нажать «🖍️ Интерактивная доска»

- [ ] Центральная зона меняется на белый холст
- [ ] Справа появляется панель «🎨 Инструменты» (кисть, ластик, очистить)
- [ ] Студия эфира остаётся видна

2. Нажать «💻 Мониторинг ПК»

- [ ] Возвращается сетка мониторинга
- [ ] Панель инструментов доски скрывается

### Список проверок — Интерактивная доска
1. Переключиться на вкладку доски
2. Рисовать мышью по холсту

- [ ] Линия появляется при удержании кнопки мыши
- [ ] Цвет меняется через выбор цвета
- [ ] Толщина меняется через ползунок
- [ ] Ластик стирает нарисованное
- [ ] Кнопка 🗑️ очищает весь холст

### Список проверок — Студия трансляции
- [ ] Видна секция управления трансляцией
- [ ] Есть превью-область с надписью «Нет активного потока»
- [ ] Есть выбор качества (1080p / 720p / 480p)
- [ ] Есть переключатель FPS (30 / 60)
- [ ] Кнопка «Начать эфир»

1. Нажать «Начать эфир»
2. Выбрать экран/окно в диалоге

- [ ] В окне предварительного просмотра виден выбранный экран
- [ ] Кнопка меняется на «Остановить трансляцию»
- [ ] У подключенных через обозреватель участников появляется видео

3. Нажать «Остановить эфир»

- [ ] Окно просмотра возвращается к исходному состоянию
- [ ] Видео исчезает

### Список проверок — Запись
1. Нажать «🔴 Запись»

- [ ] Кнопка меняется на «⏹ Стоп» (красный цвет)
- [ ] Появляется таймер 00:00
- [ ] Таймер отсчитывает вверх (00:01, 00:02…)

2. Подождать несколько секунд, нажать «⏹ Стоп»

- [ ] Автоматически скачивается файл `запись_YYYY-MM-DDTHH-MM-SS.webm`
- [ ] Кнопка возвращается к «🔴 Запись»
- [ ] Таймер скрывается
- [ ] Скачанный файл воспроизводится (видно содержимое окна приложения)

### Список проверок — Обмен сообщениями (Учитель ↔ Удаленные участники)
1. Открыть http://localhost:3000, войти как «Студент-1»
2. В учительском приложении написать сообщение

- [ ] Сообщение видно удаленному участнику
- [ ] Сообщение удаленного участника видно учителю
- [ ] Отображается имя отправителя

### Список проверок — Список участников
- [ ] В левой панели «🏠 Онлайн» отображается число подключённых
- [ ] Имена удаленных участников видны в списке

## Этап 5: Комплексный тест (всё вместе)

### Сценарий
1. Запустить сервер
2. Запустить учителя (Electron)
3. Запустить агента (Electron) — на том же или другом ПК
4. Открыть http://localhost:3000 в браузере — войти как «Студент-1»
5. Открыть другую вкладку http://localhost:3000 — войти как «Студент-2»

### Общий список проверок

**Участники:**
- [ ] У учителя в левой панели: 1 агент + 2 удаленных пользователя
- [ ] Счётчики обновляются при подключении/отключении

**Обмен сообщениями:**
- [ ] Учитель отправляет → видят все (агент + оба онлайн)
- [ ] Студент-1 отправляет → видят учитель + Студент-2 + агент
- [ ] Агент отправляет → видят все

**Трансляция:**
- [ ] Учитель начинает эфир → видео появляется у обоих студентов и у агента
- [ ] Учитель останавливает → видео исчезает у всех

**Доска:**
- [ ] Учитель рисует на доске → линии появляются у всех участников
- [ ] Учитель очищает доску → холст очищается у всех

**Мониторинг:**
- [ ] Карточка агента показывает актуальный снимок экрана
- [ ] Кнопка «🖱️ Управление» открывает модальное окно

**Запись:**
- [ ] При включённом эфире и рисовании — запись захватывает всё
- [ ] Скачанный .webm воспроизводится корректно

## Частые проблемы

| Проблема | Решение |
|---|---|
| `EADDRINUSE :3000` | Порт занят. `taskkill /PID <PID> /F` |
| `Cannot read properties of undefined (reading 'whenReady')` | Electron модуль конфликтует. Используй `.\node_modules\.bin\electron.cmd .` |
| Агент не находит сервер | Проверь, что UDP порт 41234 не блокируется фаерволлом |
| Сетевое подключение не работает | Проверь, что сервер запущен и доступен |
| Доска не синхронизируется | Убедись, что оба пользователя подключены к одному серверу |
| Скриншоты не обновляются | Проверь консоль агента на ошибки `desktopCapturer` |
| Запись не работает | Запись работает только внутри Electron (не в браузере) |

## Проверка на одном ПК (быстрая)

Если у тебя один компьютер, этого достаточно для 90% тестов:

1. **Терминал 1**: `cd server && cmd /c node server.js`
2. **Терминал 2**: `cd agent && cmd /c .\node_modules\.bin\electron.cmd .`
3. **Браузер 1**: `http://localhost:3000` → войти как «Студент-1»
4. **Браузер 2** (другая вкладка): `http://localhost:3000` → войти как «Студент-2»

> [!TIP]
> Учительское приложение пока тестируй через файл `teacher/renderer/index.html`, открыв его напрямую в браузере. Функции чата и эфира будут работать, если в `script.js` сокет подключается к `localhost:3000`.
