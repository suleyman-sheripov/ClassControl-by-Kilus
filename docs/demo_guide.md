# 🎬 Инструкция: демонстрация ClassControl на одном ПК

> Цель — записать видео для слайда презентации, показав все ключевые фишки системы,
> работая при этом на одном компьютере.

---

## 📐 Общая идея раскладки экрана

Система состоит из 3 компонентов, и все они будут запущены одновременно:

| Компонент | Что это | Как открыт |
|-----------|---------|------------|
| **Учитель** | Electron-приложение (главный пульт) | Левая половина экрана |
| **Агент (ученик)** | Electron-приложение (фоновый процесс + чат из трея) | Иконка в трее + всплывающее окно чата |
| **Онлайн-участник** | Браузер → `http://localhost:3000` | Правая половина экрана |

```
┌──────────────────────────────────────────────────────────┐
│                    Весь твой экран                        │
│  ┌─────────────────────┐  ┌─────────────────────────┐   │
│  │                     │  │                         │   │
│  │   🧑‍🏫 УЧИТЕЛЬ        │  │  🌐 ОНЛАЙН-УЧАСТНИК     │   │
│  │   (Electron)        │  │  (Браузер)              │   │
│  │                     │  │                         │   │
│  │                     │  │                         │   │
│  └─────────────────────┘  └─────────────────────────┘   │
│                                                          │
│  🔽 В трее: иконка агента (ученик)                       │
└──────────────────────────────────────────────────────────┘
```

## 🛠 Этап 0: Подготовка (до записи)

### 0.1. Убедись, что зависимости установлены

```powershell
cd d:\Backup\Desktop\DEMO-DIPLOM\server
npm install

cd d:\Backup\Desktop\DEMO-DIPLOM\teacher
npm install

cd d:\Backup\Desktop\DEMO-DIPLOM\agent
npm install
```

### 0.2. Подготовь рабочий стол

1. **Закрой всё лишнее** — браузерные вкладки, мессенджеры, Telegram и прочее. На рабочем столе не должно быть ничего постороннего.
2. **Убери уведомления Windows** — включи режим «Фокусировка внимания» (Focus Assist) → **Только будильники** через Центр уведомлений (Win + A).
3. **Разрешение экрана** — если у тебя 4K, убедись, что масштаб 100–125%, чтобы элементы UI были видны на записи.
4. **Тёмная тема Windows** — включи, если ещё не включена. ClassControl тёмный, и светлая рамка окон будет выбиваться.

### 0.3. Подготовь браузер

Открой **Chrome / Edge** и:
- Создай отдельный профиль «Демо» (или используй режим инкогнито).
- Убери панель закладок (Ctrl + Shift + B).
- Убери расширения из панели, чтобы было чисто.

## 🚀 Этап 1: Запуск (порядок важен!)

> ⚠️ **Порядок запуска критичен!** Учитель запускает сервер внутри себя,
> поэтому его нужно стартовать первым.

### Шаг 1. Запусти Учителя

```powershell
cd d:\Backup\Desktop\DEMO-DIPLOM\teacher
npm start
```

Откроется окно **ClassControl — Учитель**. Подожди 2–3 секунды, пока сервер поднимется (смотри в консоли `[SERVER] Listening on port 3000`).

> 💡 **Совет:** Не закрывай терминал — он должен работать в фоне.

### Шаг 2. Запусти Агента (Ученика)

Открой **новый терминал**:

```powershell
cd d:\Backup\Desktop\DEMO-DIPLOM\agent
npm start
```

Агент уйдёт в трей (в правом нижнем углу панели задач). Окна не будет — это нормально! Через несколько секунд агент обнаружит сервер по LAN Discovery.

> 💡 В окне учителя должна появиться карточка компьютера — это агент подключился.

### Шаг 3. Открой Онлайн-участника

В подготовленном браузере открой:

```
http://localhost:3000
```

Введи имя (например: **«Иванов А.В.»**) и нажми **«Присоединиться»**.

## 🖥 Этап 2: Раскладка окон

### Windows Snap (Win + стрелки)

1. Кликни на окно **Учителя** → нажми **Win + ←** (прикрепить влево).
2. Кликни на окно **Браузера** (онлайн-участник) → нажми **Win + →** (прикрепить вправо).

Теперь оба окна занимают по половине экрана.

> 💡 Если хочется соотношение 60/40 (учитель побольше) — перетяни разделитель мышкой.

### Трей

Убедись, что иконка агента видна в трее. Если она скрыта — нажми стрелку **˄** в трее, чтобы она была видна при записи.

## 🎥 Этап 3: Запись — Сценарий демонстрации

> 📌 Ниже — готовый пошаговый сценарий. Делай **одну фишку за раз**, не торопись.
> Каждую фишку можно записать отдельным дублем.

---

### 🎬 Сцена 1: Мониторинг компьютеров (30 сек)

**Что показать:**
1. В окне учителя → вкладка **💻 Мониторинг** активна.
2. Видна карточка подключённого агента с **живым скриншотом** (обновляется каждую секунду).
3. Переключись на агентский экран (открой там что-нибудь — например, калькулятор или Блокнот) и покажи, как скриншот обновился в режиме реального времени.

**Действия:**
- Открой поверх агентского скрытого окна какое-нибудь заметное окно.
- Подожди 2–3 секунды — на карточке учителя миниатюра поменяется.

> 💡 **Лайфхак:** Так как агент делает скриншот всего экрана, он будет видеть и окно учителя тоже. Это нормально, не обращай внимания — при реальном использовании они на разных компьютерах.

---

### 🎬 Сцена 2: Чат + отправка файлов (40 сек)

**Что показать:**
1. **Из окна учителя** напиши сообщение в чат (левая панель): `Добрый день! Начнём урок.`
2. **Из трея** — кликни правой кнопкой по иконке агента → **«💬 Открыть беседу»**.
3. В открывшемся окне чата агента **напиши ответ**: `Здравствуйте!`
4. **Из браузера** (онлайн-участник) тоже напиши: `Подключился!`
5. Покажи, что **все 3 видят все сообщения**.
6. Отправь файл через чат (перетащи или через 📎).

**Раскладка для этой сцены:**
```
┌─────────────────────┐  ┌─────────────────────────┐
│  🧑‍🏫 Учитель          │  │  🌐 Онлайн-участник     │
│  (чат слева)        │  │  (чат справа)           │
└─────────────────────┘  └─────────────────────────┘
         ┌─────────────────────┐
         │  💬 Чат агента       │ ← всплывающее окно из трея
         │  (поверх всего)     │
         └─────────────────────┘
```

> 💡 Окно чата агента маленькое (400×600), расположи его по центру экрана поверх остальных окон.

---

### 🎬 Сцена 3: Онлайн-доска (30 сек)

**Что показать:**
1. В окне учителя переключись на вкладку **🖍 Доска**.
2. Нарисуй что-нибудь (например, формулу или простую диаграмму).
3. Покажи, что **рисунок синхронно появляется** в браузере онлайн-участника.
4. Очисти доску → покажи, что она очистилась у всех.

---

### 🎬 Сцена 4: Демонстрация экрана учителя (30 сек)

**Что показать:**
1. В окне учителя нажми **«▶ Начать демонстрацию»** (правая панель).
2. У агента автоматически откроется **полноэкранное окно демонстрации** — покажи это (❗ нажми **Esc** или **Alt+F4**, чтобы закрыть его после показа, иначе оно перекроет всё).
3. В браузере онлайн-участника появится **видео трансляции**.
4. Останови демонстрацию.

> ⚠️ **Внимание:** Демо-окно агента откроется fullscreen и поверх всего!
> Будь готов его закрыть. Можно записать эту сцену отдельно.

---

### 🎬 Сцена 5: Демонстрация экрана онлайн-участника (20 сек)

**Что показать:**
1. В браузере онлайн-участника нажми **«📺 Показать мой экран»**.
2. Покажи, что появился **обратный таймер 5:00**.
3. В окне учителя видно, что участник демонстрирует экран.
4. Учитель **досрочно закрывает** демонстрацию участника.

---

### 🎬 Сцена 6: Запись экрана (бонус, 15 сек)

**Что показать:**
1. Нажми 🔴 в заголовке окна учителя.
2. Покажи, что идёт запись (индикатор).
3. Останови запись → покажи, что файл сохранился.

## 💡 Советы по записи

### Какую программу использовать для записи

| Программа | Плюсы |
|-----------|-------|
| **OBS Studio** (рекомендую) | Бесплатно, захват всего экрана, можно выделить зону |
| **ShareX** | Простой, GIF/MP4, быстрый |
| **Windows (Win + G)** | Встроенный, но записывает только одно окно |
| **PowerPoint** | Встроенная запись экрана через вкладку «Вставка» |

> 🎯 **Лучший вариант:** Используй **OBS Studio** с захватом **всего экрана** (Display Capture).
> Так ты одновременно покажешь и учителя, и браузер, и окно чата.

### Настройки записи

- **Разрешение:** записывай в 1920×1080 (Full HD).
- **FPS:** 30 — достаточно для демо.
- **Формат:** `.mp4` (H.264) — вставишь прямо в PowerPoint.
- **Без звука / со звуком:** если ты будешь озвучивать презентацию вживую, записывай **без звука** (или с тихой фоновой музыкой). Если нужен полностью автономный видеоролик — пиши **с микрофоном**.

### Общие советы

1. **Не торопись.** Зритель должен успеть прочитать текст на экране.
2. **Движения мышкой — плавные.** Не дёргай курсор.
3. **Записывай каждую фишку отдельным дублем.** Если что-то пошло не так — перезапись только одного фрагмента.
4. **Используй увеличенный курсор** — Параметры Windows → Специальные возможности → Указатель мыши → увеличь размер, чтобы его было видно на записи.

## 🔄 Этап 4: Завершение и перезапуск

### Если нужна переделка

```powershell
# Закрой всё:
# 1. Закрой окно учителя (крестик)
# 2. Закрой браузер
# 3. Агент — убей из диспетчера задач (Ctrl+Shift+Esc → classcontrol-agent → Завершить)

# Проверь, что порт 3000 свободен:
netstat -ano | findstr :3000

# Если нет — убей процесс:
# taskkill /PID <PID_из_вывода> /F

# Перезапусти всё заново с Этапа 1
```

### Если всё ОК — обрежь видео

Открой записи в видеоредакторе (CapCut, DaVinci Resolve, или даже встроенный Clipchamp в Windows 11) и нарежь по фишкам.

## 🆘 Решение частых проблем

| Проблема | Решение |
|----------|---------|
| Агент не подключается | Подожди 5–10 сек, LAN Discovery работает с интервалом 3 сек. Убедись, что сервер запущен (порт 3000). |
| Порт 3000 занят | `netstat -ano | findstr :3000` → `taskkill /PID <PID> /F` |
| Онлайн-участник не видит демонстрацию | Проверь, что в браузере разрешён WebRTC. Используй Chrome. |
| Демо-окно агента перекрыло всё | `Alt + F4` или `Alt + Tab` для переключения, затем закрой окно демо. |
| Скриншоты не обновляются | Перезапусти агента. |
| Ошибки в консоли Node.js | Сверься с `verification_guide.md` в корне проекта. |
