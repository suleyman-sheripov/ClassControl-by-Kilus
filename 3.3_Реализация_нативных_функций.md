## 3.3 Программная реализация встроенных функций приложения

Одной из ключевых задач при разработке фонового агента локального ученика являлась его глубокая интеграция с операционной системой. В отличие от стандартных браузерных приложений, агент должен функционировать скрыто от пользователя, автоматически запускаться при старте системы и предоставлять преподавателю возможность дистанционного управления мышью и клавиатурой. Эти возможности были реализованы средствами платформы Electron.js и встроенных функций Node.js.

Для предотвращения несанкционированного закрытия программы учеником главное окно приложения создается с флагом `show: false`, что делает его невидимым на панели задач. Взаимодействие с программой осуществляется исключительно через иконку в системном трее. В целях безопасности и поддержания дисциплины из контекстного меню трея намеренно исключен пункт «Выход». Автоматический запуск агента при включении компьютера реализован через внесение записи в системный реестр ОС с использованием встроенного метода `app.setLoginItemSettings`.

В листинге 3.2 представлена программная реализация жизненного цикла фонового приложения-агента, включая настройку автозапуска и инициализацию скрытого режима.

```javascript
// Настройка автоматического запуска при старте ОС
app.setLoginItemSettings({
  openAtLogin: true,
  path: app.getPath('exe'),
  args: ['--hidden']
});

function createTray() {
  const iconPath = path.join(__dirname, 'assets', 'icon.png');
  tray = new Tray(iconPath);
  tray.setToolTip('ClassControl Agent');

  // Контекстное меню без возможности закрытия приложения
  const contextMenu = Menu.buildFromTemplate([
    { label: '💬 Открыть чат', click: () => openChatWindow() }
  ]);
  tray.setContextMenu(contextMenu);
}

function createHiddenWindow() {
  hiddenWindow = new BrowserWindow({
    show: false, // Окно скрыто от пользователя
    width: 400,
    height: 300,
    webPreferences: { preload: path.join(__dirname, 'preload.js') }
  });
  hiddenWindow.loadFile(path.join(__dirname, 'renderer', 'index.html'));
}
```

Второй важнейшей встроенной функцией системы является дистанционное перехватывание управления. Для программного повторения движений мыши и нажатий клавиш была добавлена специализированная библиотека. При получении агентом события по сети с координатами указателя от приложения преподавателя, программа вызывает функции, которые на уровне операционной системы физически перемещают системный указатель. Аналогичным образом обрабатываются нажатия кнопок мыши и ввод текста. Это предоставляет преподавателю возможность в реальном времени брать управление на себя и исправлять ошибки на компьютере учащегося без физического подхода к его рабочему месту.
