## 1. Общее описание проекта

**ClassControl** — настольное приложение для управления компьютерным классом, аналог Veyon Master / LiteManager. Система состоит из двух настольных Electron-приложений (Учитель и Ученик) и интерфейса обозревателя для удалённых участников. Все компоненты работают внутри одной локальной Wi-Fi / Ethernet сети. Удаленные участники подключаются из дома через интернет.

### 2.1. Компоненты

| Компонент | Технология | Описание |
|-----------|-----------|----------|
| **Сервер** | Node.js + Express + Socket.IO | Центральный узел. Запускается на ПК учителя. Обслуживает WebSocket-соединения, передачу сигналов WebRTC, беседу, передачу файлов. |
| **Учитель (Главный)** | Electron (настольное) | Основное приложение учителя. Окно с мониторингом, доской, трансляцией, беседой. Включает в себя встроенный сервер. |
| **Ученик-Агент** | Electron (настольное) | Фоновое приложение. Находится в области уведомлений. Отправляет снимки экрана каждую секунду, принимает команды управления, отображает демонстрацию учителя. |
| **Удаленный участник** | Страница обозревателя | Минимальный интерфейс: беседа + просмотр демонстрации + возможность показать свой экран (5 мин). |

## 3. Роли и их возможности

### 3.1. 🧑‍🏫 Учитель (Master)

| Возможность | Описание |
|-------------|----------|
| **Мониторинг ПК** | Сетка карточек со снимками экранов всех локальных ученических ПК. Обновление снимков — **1 раз в секунду**. |
| **Удалённое управление** | Нажатие по карточке ПК → полноэкранный режим удалённого управления (мышь + клавиатура) через `@computer-use/nut-js`. |
| **Интерактивная доска** | Полноэкранный холст для рисования (кисть, ластик, цвет, толщина). Рисунки транслируются в реальном времени всем (лочным и удаленным участникам). |
| **Демонстрация экрана** | Захват экрана/окна учителя → трансляция через WebRTC всем участникам. На локальных ПК — разворачивается на весь экран. Удаленные участники смотрят в обозревателе. |
| **Беседа** | Общий обмен текстовыми сообщениями с возможностью отправки файлов. Виден всем. |
| **Запись экрана** | Запись всего, что происходит в окне приложения учителя (мониторинг → доска → демонстрация). Автоматически переключает источник записи при смене вкладки. Записывает микрофон учителя + голоса удаленных участников. |
| **Настройки трансляции** | Качество (1080p / 720p / 480p / 360p), кадры/с (30 / 60), выбор окна. Настраиваются **до** начала трансляции. |
| **Управление агентами** | Блокировка экранов, отправка сообщений ученикам, принудительное закрытие программ. |

### 3.2. 🧑‍💻 Ученик-Агент (Локальный ПК в классе)

| Возможность | Описание |
|-------------|----------|
| **Показ экрана учителю** | Агент каждую секунду делает снимок экрана и отправляет на сервер для мониторинга. |
| **Приём удалённого управления** | Учитель может перехватить мышь и клавиатуру. |
| **Просмотр демонстрации** | При старте демонстрации экран ученика показывает поток учителя на весь экран. |
| **Просмотр доски** | Интерактивная доска учителя отображается в окне агента. |
| **Беседа** | Ученик может писать в общую беседу и отправлять файлы. Доступ к беседе — через нажатие правой кнопкой мыши по значку в области уведомлений. |
| **❌ НЕ может** | Менять настройки агента. Закрыть/выключить агента. Иметь ярлыки на рабочем столе. |

### 3.3. 🌐 Удаленный участник (Из дома, через обозреватель)

| Возможность | Описание |
|-------------|----------|
| **Просмотр демонстрации** | Видит трансляцию экрана / доски учителя. |
| **Беседа** | Текстовая беседа + отправка файлов. |
| **Показ своего экрана** | Может добровольно включить демонстрацию экрана учителю. **Ограничение: 5 минут**. На экране виден обратный таймер. Учитель может закрыть их демонстрацию досрочно. |
| **❌ НЕ может** | Быть удалённо управляемым. Видеть мониторинг других ПК. Менять настройки. |

## 5. Интерфейс ученика-агента

### 5.1. Поведение

- **Автозапуск:** Прописывается в реестр Windows (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- **Область уведомлений:** Значок в системной области уведомлений. Нажатие левой кнопкой мыши — ничего. Нажатие правой кнопкой мыши — контекстное меню с **единственным пунктом**: `💬 Открыть беседу`. Пункта «Выход» **нет**.
- **Ярлыки:** На рабочем столе ярлык **не создаётся**. Доступ только через меню «Пуск» (как Veyon Configurator).
- **Окно:** Основное окно скрыто. Открывается только беседа (плавающее окно) или полноэкранная демонстрация учителя.

## 7. Функции (Подробное описание)

### 7.1. Мониторинг экранов (1 кадр/с)

- Каждый ученик-агент раз в секунду делает снимок экрана (`electron.desktopCapturer`).
- Сжимает до JPEG, качество ~30%, разрешение ~320×180.
- Отправляет через Socket.IO серверу.
- Сервер пересылает его Master-приложению учителя.
- Master отображает снимки в карточках сетки мониторинга.

### 7.2. Удалённое управление

- Учитель нажимает по карточке → открывается всплывающее окно с полноэкранным видеопотоком (WebRTC) и перехватом мыши/клавиатуры.
- Ученик-агент выполняет действия через `@computer-use/nut-js` (движение мыши, клики, нажатия клавиш, скролл).

### 7.3. Демонстрация экрана (Учитель → Все)

- Учитель выбирает качество и кадры/с **до** начала трансляции.
- Нажимает «Начать трансляцию» → обозреватель/Electron показывает системный диалог выбора экрана/окна.
- Видеопоток через WebRTC отправляется:
  - **Локальным агентам** — разворачивается на весь экран ученического ПК.
  - **Удаленным участникам** — отображается в их обозревателе.
- Предварительный просмотр трансляции постоянно виден в правой панели учителя.

### 7.4. Интерактивная доска

- Полноэкранный холст (HTML5) с инструментами:
  - **Кисть** — рисование произвольных линий.
  - **Ластик** — стирание (через `destination-out`).
  - **Цвет** — выбор цвета кисти.
  - **Толщина** — ползунок толщины линии.
  - **Очистить** — полностью стереть доску.
- Все действия синхронизируются через Socket.IO в реальном времени.
- Видна всем: и локальным агентам, и удаленным участникам.

### 7.5. Беседа с передачей файлов

- Общая беседа для всех участников (учитель, агенты, удаленные).
- Текстовые сообщения передаются через Socket.IO.
- **Передача файлов:**
  - Пользователь нажимает 📎, выбирает файл.
  - Файл загружается на сервер (в папку `uploads/`).
  - Сервер рассылает всем ссылку на скачивание.
  - Ограничение: ~50 МБ на файл.

### 7.6. Запись экрана (Учитель)

- Кнопка «🔴 Запись» в заголовке окна учителя.
- Использует встроенные функции записи для фиксации содержимого окна приложения.
- **Автопереключение источника:**
  - Если открыта вкладка «Мониторинг» → записывает сетку мониторинга.
  - Если открыта вкладка «Доска» → записывает доску.
  - Если идёт демонстрация экрана → записывает демонстрацию.
- **Аудио:** Записывает микрофон учителя + системные звуки (голоса удаленных участников).
- Файл сохраняется в формате `.webm` в папку `Документы/ClassControl/Записи/`.

### 7.7. Демонстрация экрана удаленного участника (5 мин)

- Удаленный участник может добровольно показать свой экран учителю.
- После начала на экране участника появляется **обратный таймер** (05:00).
- Учитель видит поток в отдельном всплывающем окне.
- По истечении 5 минут демонстрация автоматически прекращается.
- Учитель может закрыть демонстрацию досрочно.

### 7.8. Автообнаружение в сети

- При запуске Master-приложение отправляет UDP-broadcast в локальную сеть.
- Ученики-агенты, получив broadcast, отвечают серверу своим IP и именем.
- Или: Ученики-агенты при старте ищут сервер по заданному порту (например, 3000) через multicast.
- Никаких ручных IP-адресов вводить не нужно.

## 8. Безопасность и ограничения ученика-агента

| Аспект | Реализация |
|--------|-----------|
| **Автозапуск** | Запись в реестр Windows: `HKCU\...\Run`. |
| **Скрытие ярлыков** | Установщик (`electron-builder`) НЕ создаёт ярлык на рабочем столе. Только меню «Пуск». |
| **Область уведомлений** | Контекстное меню содержит только `💬 Открыть беседу`. Пункт «Выход» отсутствует. |
| **Настройки заблокированы** | Ученик не имеет доступа к настройкам агента. Настройки задаются при установке или удалённо учителем. |
| **Фоновый режим** | Окно приложения скрыто. Видна только иконка в трее. |

| Компонент | Технология |

| Установщик | **electron-builder** (NSIS для Windows) |
| Сборка | **electron-builder** → `.exe` |

## 11. Требования к сборке и установке

### 11.1. Учитель (Master)
- Собирается через `electron-builder` в `.exe`.
- При установке: ярлык в меню «Пуск», иконка на рабочий стол (опционально).
- При запуске: открывается главное окно, автоматически запускает встроенный сервер.

### 11.2. Ученик (Agent)
- Собирается через `electron-builder` в `.exe`.
- При установке: ярлык **только** в меню «Пуск» (как «ClassControl Configurator»). Никакого ярлыка на рабочем столе.
- Добавляется в автозапуск Windows (реестр `Run`).
- При запуске: окно скрыто, иконка в трее, начинает отправлять скриншоты серверу.

## 12. Нефункциональные требования

- **Локальная работа:** Всё работает без интернета внутри одной LAN. Интернет нужен только для онлайн-участников.
- **Производительность:** Мониторинг снимков экрана не должен загружать процессор > 10% на ученическом ПК.
- **Стабильность:** При потере связи агент автоматически переподключается к серверу каждые 5 секунд.
- **Масштабируемость:** Поддержка до 30 агентов одновременно.
