# Инструкция по реализации ClassControl

> **ВНИМАНИЕ:** Прочитай `TZ.md` в корне проекта перед началом работы.
> Выполняй этапы строго последовательно. Каждый заканчивается проверкой.

---

## Этап 0: Подготовка проекта

### 0.1. Реструктуризация папок
Перейти к целевой структуре:
```
DEMO-DIPLOM/
├── server/    # Express + Socket.IO
├── teacher/   # Electron-приложение учителя
├── agent/     # Electron-приложение ученика (модифицируем)
├── online/    # Веб-интерфейс онлайн-участников
└── TZ.md
```
1. Создай `server/`, перенеси `server.js` → `server/server.js`.
2. Создай `teacher/` — новое Electron-приложение учителя.
3. Создай `online/` — сюда переедет интерфейс из `public/`.
4. `agent/` оставь, модифицируем позже. Удали `public/` после миграции.

### 0.2. Зависимости
- `server/`: `express`, `socket.io`, `multer`
- `teacher/`: `electron` (dev), серверный код подключается напрямую
- `agent/`: `electron` (dev), `@computer-use/nut-js`, `socket.io-client`

**✅ Проверка:** `npm install` без ошибок в каждой папке.

## Этап 1: Сервер

### 1.1. Socket.IO события (`server/server.js`)

**Регистрация:** `register-teacher`, `register-agent`, `register-online-user`
**Мониторинг:** `agent-screenshot` (агент→сервер→учитель), `request-agents-list`
**Управление:** `request-agent-screen`, `agent-control` (мышь/клавиатура)
**Демонстрация:** `start-broadcast`, `stop-broadcast`, WebRTC: `offer`, `answer`, `ice-candidate`
**Доска:** `draw` ({x0,y0,x1,y1,color,width,tool}), `clear-canvas`
**Чат:** `chat-message` ({sender,text,timestamp}), `chat-file` ({sender,filename,url,size})
**Онлайн-демо:** `online-user-share-screen`, `online-user-stop-share`, `teacher-close-share`

### 1.2. Файлы
`multer` для POST `/upload` → сохранять в `server/uploads/`. После загрузки эмитить `chat-file`.

### 1.3. LAN Discovery
Сервер слушает UDP `41234`. Агенты шлют broadcast `CLASSCONTROL_DISCOVER`. Сервер отвечает `CLASSCONTROL_SERVER:IP:PORT`. Агент подключается по полученному адресу.

**✅ Проверка:** Сервер на порту 3000, статика из `online/`, Socket.IO работает.

## Этап 2: Учитель (Electron Master)

### 2.1. Main process (`teacher/main.js`)
1. Запускает встроенный сервер (`../server/server.js`).
2. Открывает BrowserWindow (1400×900, min 1200×700).
3. `contextIsolation: true`, `nodeIntegration: false`, `preload.js`.

### 2.2. HTML (`teacher/renderer/index.html`)
3-колоночный макет:
- **Заголовок:** кнопка 🔴 Запись, название кабинета.
- **Левая панель (280-320px):** список онлайн-участников + общий чат (текст + файлы).
- **Центр (flex):** табы [💻 Мониторинг] / [🖍️ Доска]. Мониторинг = сетка карточек ПК. Доска = полноэкранный canvas.
- **Правая панель (280-320px):** превью трансляции, настройки (качество, FPS), кнопки старт/стоп, инструменты доски.
- **Статус-бар:** кол-во агентов, онлайн-участников, IP сети.

### 2.3. Стили (`teacher/renderer/style.css`)
Тёмная тема: фон `#0f1117`, панели `#1a1d27`, акцент `#6366f1`. Шрифт Inter. Скругления 8/12px. Анимации `transition: 0.2s ease`. Карточки с ховером (подсветка + увеличение).

### 2.4. Логика (`teacher/renderer/script.js`)
Функции в порядке приоритета:
1. `connectToServer()` — Socket.IO к `localhost:3000`
2. `updateMonitoringGrid(agents)` — рендер карточек с миниатюрами
3. Обновление скриншотов по событию `agent-screenshot`
4. `switchTab('monitoring'|'whiteboard')` — переключение вкладок
5. Онлайн-доска (кисть, ластик, цвет) — мигрировать из текущего кода
6. `startBroadcast()`/`stopBroadcast()` — WebRTC демонстрация
7. Чат: `sendMessage()`, `sendFile()`, рендер сообщений
8. `openRemoteControl(agentId)` — модалка с видеопотоком + перехват
9. `startRecording()`/`stopRecording()` — MediaRecorder

**✅ Проверка:** Приложение запускается, 3-колоночный макет, карточки агентов, табы, чат.

## Этап 3: Ученик-Агент

### 3.1. Main process (`agent/main.js`)
1. **Трей:** иконка в трее. Правый клик → только «💬 Открыть чат». Пункта «Выход» НЕТ.
2. **Автозапуск:** `app.setLoginItemSettings({ openAtLogin: true })`.
3. **Скрытое окно:** `show: false` — фоновая работа (скриншоты, WebRTC).
4. **Окно чата:** отдельное BrowserWindow (chat.html), 400×600, из трея.
5. **Окно демонстрации:** отдельное BrowserWindow (demo.html), fullscreen — при трансляции учителя.

### 3.2. LAN Discovery
При запуске UDP broadcast `CLASSCONTROL_DISCOVER` на `255.255.255.255:41234`. По ответу — подключение через Socket.IO.

### 3.3. Скриншоты (1 FPS)
Каждую секунду: `desktopCapturer.getSources` → thumbnail 320×180 → JPEG 30% → `socket.emit('agent-screenshot')`.

### 3.4. Демонстрация
`broadcast-started` → открыть fullscreen окно с WebRTC-потоком. `broadcast-stopped` → закрыть.

### 3.5. Чат (`agent/renderer/chat.html`)
Список сообщений + ввод + кнопка 📎 для файлов. Socket.IO: `chat-message`, `chat-file`.

**✅ Проверка:** Агент в трее, чат из трея, скриншоты идут, демонстрация открывается fullscreen.

## Этап 4: Онлайн-участник

### 4.1. Вход (`online/index.html`)
Поле «Имя» + кнопка «Присоединиться».

### 4.2. Интерфейс
- Слева: видео демонстрации / онлайн-доска (canvas).
- Справа: чат (текст + файлы).
- Снизу: кнопка «📺 Показать мой экран (макс. 5 мин)».

### 4.3. Демонстрация участника
При нажатии — `getDisplayMedia`, обратный таймер 5:00→0:00, auto-stop. Учитель может закрыть досрочно.

**✅ Проверка:** Браузер → чат, демонстрация учителя, показ экрана с таймером 5 мин.

## Этап 5: Запись экрана учителя

- Кнопка 🔴 в заголовке. `desktopCapturer` захватывает окно приложения.
- `MediaRecorder` → `.webm` в `Документы/ClassControl/Записи/`.
- Аудио: микрофон + системный звук.
- Автопереключение: записывается содержимое окна, поэтому смена вкладок автоматически отражается.

**✅ Проверка:** Запись сохраняется, видно вкладки, слышен звук.

## Этап 6: Сборка

**Учитель:** `electron-builder`, NSIS, ярлык на рабочем столе + меню Пуск.
**Агент:** `electron-builder`, NSIS, ярлык **только** в меню Пуск (без рабочего стола), автозапуск.

```bash
cd teacher && npx electron-builder --win
cd agent && npx electron-builder --win
```

**✅ Проверка:** `.exe` собраны. Учитель — ярлык на столе. Агент — только Пуск, автозапуск.
