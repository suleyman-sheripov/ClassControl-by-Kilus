В установщик входит фиксированная версия cloudflared.

`scripts/vendor-cloudflared.js` скачивает официальный файл, проверяет SHA-256 по `cloudflared-manifest.json`, затем готовит каталог `win-x64`, `mac-x64`, `mac-arm64` и т. д. При сборке это вызывает before-pack. Архив macOS распаковывается только после успешной проверки.

В приложении проверяется SHA-256 исполняемого файла. Непроверенного скачивания «latest» во время урока больше нет. Контрольные суммы релиза взяты из опубликованных GitHub digest по URL `source` в манифесте. При обновлении версии сверяйте их с официальным релизом; не заменяйте ожидаемый хеш после ошибки проверки.
