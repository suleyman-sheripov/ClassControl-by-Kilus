## 3.4 Программная реализация мультимедийных функций

Ключевым аспектом системы «ClassControl» является обработка мультимедийных данных и трансляция графического содержимого в реальном времени. В данную категорию входят функции фонового мониторинга локальных рабочих станций, интерактивная доска и полноэкранная трансляция экрана.

**Фоновый захват экрана**
Для реализации визуального мониторинга компьютеров используется встроенный интерфейс платформы. Локальный агент каждую секунду программно запрашивает снимок основного монитора системы. Для предотвращения перегрузки сети полученное изображение предварительно обрабатывается на стороне клиента: оно уменьшается до 320x180 пикселей и кодируется в формат JPEG со сжатием до 30%. В листинге 3.3 представлена реализация обработчика, выполняющего захват изображения.

```javascript
const { ipcMain, desktopCapturer } = require('electron');

// Обработчик для создания скриншотов рабочего стола
ipcMain.handle('take-screenshot', async () => {
  const sources = await desktopCapturer.getSources({
    types: ['screen'],
    thumbnailSize: { width: 320, height: 180 }
  });
  
  // Конвертация миниатюры в JPEG (30% качество) и кодирование в Base64
  return sources?.thumbnail.toJPEG(30).toString('base64');
});
```

**Интерактивная онлайн-доска**
Функция совместного рисования реализована на базе встроенных средств отрисовки. При переключении в режим доски в приложении преподавателя активируется холст, перехватывающий координаты указателя мыши. Программа вычисляет траекторию движения и выполняет отрисовку линий. Параллельно с отрисовкой координаты передаются по сети всем клиентам, включая пользователей в обозревателях, что обеспечивает мгновенную визуальную синхронизацию.

**Видеотрансляция**
Трансляция рабочего стола преподавателя и сеансы демонстрации удаленных учеников построены на базе современных сетевых стандартов. Захват видео осуществляется с помощью системных функций записи экрана. Система предоставляет возможность предварительного выбора разрешения от 480p до 1080p и частоты 30 или 60 кадров в секунду. При старте трансляции сервер инициирует процесс установки связи, после чего устанавливается прямое соединение между компьютерами. Прямая передача медиаданных напрямую, без участия сервера, сводит задержку видео к минимуму и снижает требования к вычислительным ресурсам.
