# 1.3 Обзор инструментальных средств проектирования и разработки

Для реализации кроссплатформенной системы смешанного обучения «ClassControl» был выбран современный набор интернет-технологий, позволяющий объединить настольную программу и обозреватель в единую среду. Выбор инструментов обусловлен необходимостью обеспечения высокой скорости обмена данными в реальном времени, работы с потоковым видео и получения доступа к системным функциям операционной системы.

В качестве основы для серверной части и настольных приложений была выбрана среда выполнения **Node.js**. Ее архитектура идеально подходит для приложений с интенсивным обменом данными и множеством одновременных подключений. Совместно с ней на сервере используется сетевой программный каркас **Express**, который отвечает за обработку запросов на получение страниц, сохранение загружаемых файлов и передачу данных клиенту.

Для двустороннего обмена сообщениями без задержек применяется библиотека **Socket.IO**. Данный инструмент обеспечивает надежную доставку команд, таких как блокировка или перехват управления, работу области обмена сообщениями и передачу служебной информации для прямой связи устройств.

Создание настольных приложений для преподавателя и локальных учеников выполнено с помощью платформы **Electron.js**. Эта технология позволяет использовать стандартные средства разметки страниц для разработки полноценных программ. Использование инструмента критически важно для доступа к системным функциям: он позволил реализовать скрытую работу агента без показа на панели задач, вывод значка в область уведомлений, автозапуск через реестр и принудительный показ видео поверх остальных окон.

Для реализации ключевой функции дистанционного управления рабочими станциями учеников интегрирована библиотека **@computer-use/nut-js**. Это инструмент автоматизации рабочего стола для Node.js, который позволяет программно перехватывать и эмулировать движения мыши и нажатия клавиш клавиатуры, обеспечивая преподавателю возможность оперативного вмешательства в работу ребенка.

Организация видеотрансляции экрана преподавателя и удаленных учеников базируется на стандарте **WebRTC**. Он обеспечивает захват и передачу видео со звуком напрямую между пользователями с минимальной задержкой, что обязательно для проведения дистанционных занятий. Захват экрана и запись урока реализованы встроенными системными средствами для работы с медиа.

Внешний вид устанавливаемых программ и версии для обозревателя создан с использованием классического набора **HTML5, CSS3 и современного JavaScript**. Для модуля интерактивной доски задействован встроенный элемент разметки **Canvas**, быстро обрабатывающий графику.
